CHULBULPLAY - ADMIN PLAN API TESTING
=====================================

Base URL: http://localhost:5000
Admin header for every endpoint:
Authorization: Bearer {{adminToken}}

Get {{adminToken}} first:
POST {{baseUrl}}/api/admin/auth/login
Content-Type: application/json
{
  "email": "{{adminEmail}}",
  "password": "{{adminPassword}}"
}

All plan create and update requests use Body > raw > JSON with:
Content-Type: application/json


1. CREATE PLAN
--------------
POST {{baseUrl}}/api/admin/plan
Authorization: Bearer {{adminToken}}

Body:
{
  "name": "Monthly Premium",
  "price": 99,
  "duration": 30,
  "features": [
    "HD streaming",
    "Watch on 2 devices"
  ],
  "isActive": true,
  "planType": "monthly",
  "sortOrder": 1,
  "isRecommended": true,
  "platform": "app"
}

Required fields: `name`, `price`, `duration`.

`duration` is in days. `planType` must be one of: monthly, quarterly, yearly,
or lifetime. `platform` can be app or website; omitted/invalid values default
to app. The name + platform combination must be unique.


2. LIST ALL PLANS
-----------------
GET {{baseUrl}}/api/admin/plan
Authorization: Bearer {{adminToken}}
Body: none

Optional platform filters:
GET {{baseUrl}}/api/admin/plan?platform=app
GET {{baseUrl}}/api/admin/plan?platform=website

Without `platform`, the response contains plans from both platforms.


3. UPDATE PLAN
--------------
PATCH {{baseUrl}}/api/admin/plan/{{planId}}
Authorization: Bearer {{adminToken}}

Example Body:
{
  "name": "Monthly Premium Plus",
  "price": 149,
  "duration": 30,
  "features": [
    "Full HD streaming",
    "Watch on 4 devices"
  ],
  "planType": "monthly",
  "sortOrder": 2,
  "isRecommended": false,
  "platform": "app"
}

Only send fields that need to change. A missing plan returns HTTP 404.


4. TOGGLE PLAN STATUS
---------------------
PATCH {{baseUrl}}/api/admin/plan/{{planId}}/toggle-status
Authorization: Bearer {{adminToken}}
Body: none

This switches `isActive` between true and false.


5. DELETE PLAN
--------------
DELETE {{baseUrl}}/api/admin/plan/{{planId}}
Authorization: Bearer {{adminToken}}
Body: none

A missing plan returns HTTP 404.
