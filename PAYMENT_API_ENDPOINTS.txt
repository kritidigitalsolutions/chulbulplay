----------------------------------------------------------------
1. GET ACTIVE PAYMENT GATEWAYS
----------------------------------------------------------------
Method  : GET
URL     : /api/payment/gateways
Auth    : Not required

Body    : None

Response:
{
  "success": true,
  "gateways": {
    "sabpaisa": {
      "enabled": true,
      "name": "SabPaisa",
      "mode": "test"
    }
  }
}


----------------------------------------------------------------
2. INITIATE SABPAISA PAYMENT  [AUTH]
----------------------------------------------------------------
Method  : POST
URL     : /api/payment/sabpaisa/initiate
          /api/payment/initiate          (alias)
          /api/payment/create-order      (alias)
Auth    : Required

Headers :
  Content-Type  : application/json
  Authorization : Bearer <user_token>

Body:
{
  "planId"    : "664f1a2b3c4d5e6f7a8b9c0d",   // REQUIRED  - MongoDB Plan ID
  "name"      : "Ravi Kumar",                   // OPTIONAL  - taken from profile if missing
  "email"     : "ravi@example.com",             // REQUIRED  - valid email address
  "phone"     : "9876543210",                   // OPTIONAL  - 10-digit Indian number
  "platform"  : "app",                          // OPTIONAL  - "app" or "website" (default: app)
  "promoCode" : "SAVE20"                        // OPTIONAL  - discount/promo code
}

Response (Success):
{
  "success"     : true,
  "orderId"     : "SP_1720000000000_ab12cd34",
  "finalAmount" : 99,
  "platform"    : "app",
  "checkoutUrl" : "https://staging-checkout.sabpaisa.in/pay?session=..."
}

Response (Error - already subscribed):
{
  "success" : false,
  "message" : "You already have an active mobile app subscription"
}

Response (Error - invalid plan):
{
  "success" : false,
  "message" : "Plan not found or inactive"
}

Response (Error - no email):
{
  "success" : false,
  "message" : "A valid email address is required for SabPaisa payment"
}


----------------------------------------------------------------
3. CHECK PAYMENT STATUS  [AUTH]
----------------------------------------------------------------
Method  : GET
URL     : /api/payment/sabpaisa/status/:orderId
Auth    : Required

Example :
  GET /api/payment/sabpaisa/status/SP_1720000000000_ab12cd34
  Authorization: Bearer <user_token>

Body    : None

Response (Pending):
{
  "success" : true,
  "status"  : "pending"
}

Response (Completed):
{
  "success"      : true,
  "status"       : "completed",
  "subscription" : {
    "status"    : "active",
    "startDate" : "2024-07-01T00:00:00.000Z",
    "endDate"   : "2024-07-31T00:00:00.000Z"
  }
}

Response (Failed):
{
  "success" : true,
  "status"  : "failed"
}

----------------------------------------------------------------
5. SABPAISA RETURN URL  (AUTO - DO NOT CALL MANUALLY)
----------------------------------------------------------------
Method  : GET / POST
URL     : /api/payment/sabpaisa/return
Auth    : Not required

Note    : SabPaisa automatically redirects the user to this URL
          after payment. Do NOT call this manually.
          It activates the user's subscription on success.


----------------------------------------------------------------
6. SABPAISA WEBHOOK  (AUTO - DO NOT CALL MANUALLY)
----------------------------------------------------------------
Method  : POST
URL     : /api/payment/sabpaisa/webhook
Auth    : Not required (verified via HMAC signature)

Note    : SabPaisa's server sends payment events here automatically.
          Do NOT call this manually.


================================================================
TYPICAL PAYMENT FLOW (Step by Step)
================================================================

Step 1 - Check if SabPaisa is enabled
  GET /api/payment/gateways

Step 2 - Initiate payment (get checkout URL)
  POST /api/payment/sabpaisa/initiate
  Body: { "planId": "...", "email": "...", ... }
  => Save the returned "orderId"
  => Redirect user to "checkoutUrl"

Step 3 - User completes payment on SabPaisa checkout page

Step 4 - Poll for payment result
  GET /api/payment/sabpaisa/status/{orderId}
  => Keep polling every 3-5 seconds until status = "completed" or "failed"

================================================================
NOTES
================================================================
- All monetary amounts in the response are in INR (Rupees)
- SabPaisa requires amount >= Rs. 1 (100 paise minimum)
- Phone number must be a 10-digit Indian number starting with 6-9
- Email is mandatory for SabPaisa -- ensure user profile has one
- SABPAISA_MODE=test uses staging; SABPAISA_MODE=live uses production
